# e-plantShopping

## Paradise Nursery Shopping Application

e-plantShopping is an online plant shopping application developed using React and Redux Toolkit.

### Features
- Interactive Paradise Nursery landing page.
- About Us section.
- Three plant categories.
- Six unique plants in each category.
- Plant images, descriptions and prices.
- Add to Cart functionality.
- Dynamic shopping cart count.
- Increase and decrease item quantities.
- Remove items from the cart.
- Automatic price calculation.
- Checkout notification.
- Continue Shopping functionality.

### Technologies Used
- React.js
- Redux Toolkit
- React Redux
- JavaScript
- CSS
- Vite
- Lucide React

### Installation

1. Clone the repository.
2. Install dependencies:

   npm install

3. Start the application:

   npm run dev

4. Open the local URL displayed in the terminal.
